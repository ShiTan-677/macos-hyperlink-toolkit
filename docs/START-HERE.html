macOS Hyperlink Toolkit

中文English

安装好以后，
在「通用」里设置快捷键。

把当前网页复制成带标题的可点击链接。日常使用只需安装 HLT - Copy Rich Link。

1. 双击安装工作流

在解压后的 workflows 文件夹中，双击 HLT - Copy Rich Link.workflow，选择安装。

安装后如果打开了系统设置，接着按下方操作即可。这是 macOS 的工作流安装流程提供的设置入口；不同系统版本可能有不同表现。

2. 展开「服务」列表里的「通用」

系统设置→键盘→键盘快捷键→服务→通用

如果已经打开“键盘快捷键”，直接选择左侧的服务，再点击右侧通用左边的小三角。

位置示意（非系统截图）

▾ 通用

☑ HLT - Copy Rich Link无 → ⌥⌘K

勾选 HLT - Copy Rich Link，双击右侧的“无”或已有快捷键，同时按下 Option + Command + K。看到 ⌥⌘K 后，点击完成。

“通用”是服务列表内的分组。安装包不预设快捷键，可以选择其他组合；与旧服务冲突时，先清除旧绑定。其他 macOS 版本的分组名称或布局可能不同。

3. 复制一个链接试试

  1. 在 Safari 打开 example.com，按刚设置的快捷键。暂不设置快捷键也可以从菜单栏的 Safari → 服务 → HLT - Copy Rich Link 运行。
  2. 首次出现控制浏览器的自动化授权时，允许后重试。保持浏览器在前台，等复制完成再切换应用。启用了通知时，会看到“链接已复制”。
  3. 到空白 Excel 单元格或 TextEdit 富文本新文稿中按 ⌘V，检查是否显示可点击的 Example Domain。
安装或快捷键没有按预期工作

若双击打开的是 Automator 编辑器，关闭编辑器；若提示导入“快捷指令”，取消导入。在 Finder 中选择前往 → 前往文件夹，输入 ~/Library/Services，将工作流复制进去。文件夹不存在时，先在 ~/Library 中新建 Services。

先从浏览器的“服务”菜单测试。如果菜单能运行而快捷键无效，检查是否已勾选、组合键是否与其他操作冲突。快捷键是可选的，未设置时也能正常使用服务菜单。

可选：Excel 公式工具

需要显式写入公式时，再安装其余两个工作流。它们的快捷键也在同一个通用分组中。

服务名称用途示例快捷键
HLT - Copy Excel Hyperlink从浏览器复制超链接公式⌃⌥C
HLT - Paste Excel Formula在 Excel 中写入活动单元格⌃⌥V

公式写入会覆盖活动单元格，请先在空白测试工作簿里使用。复制公式完成后，再切回 Excel 运行写入服务。

Installed? Find your shortcut
under General.

Copy the current webpage as a clickable title. Start with HLT - Copy Rich Link; the two Excel formula tools are optional.

1. Install the workflow

In the extracted workflows folder, double-click HLT - Copy Rich Link.workflow and choose Install.

If installation opens System Settings, continue below. This settings entry point belongs to macOS’s workflow installation flow; behavior can vary by version.

2. Expand General inside Services

System Settings → Keyboard → Keyboard Shortcuts → Services → General

  1. Select Services in the Keyboard Shortcuts sidebar.
  2. Expand General using the triangle in the list on the right.
  3. Enable HLT - Copy Rich Link. Double-click “none” or the existing shortcut on the right, then press Option + Command + K.
  4. Check that ⌥⌘K appears, then click Done.

General is a group within Services. No shortcut is assigned by the package. Choose a different combination or clear an older binding if there is a conflict. Group names and layout may vary on other macOS versions.

3. Try a link

  1. Open example.com in Safari. Press your shortcut, or choose Safari → Services → HLT - Copy Rich Link without setting a shortcut.
  2. Allow the expected browser Automation request and retry if needed. Keep Safari in front until copying finishes. A success notification appears if notifications are enabled.
  3. Paste with ⌘V into an empty Excel cell or a new rich-text TextEdit document. Check for a clickable Example Domain.
If installation or the shortcut does not work

If the workflow opens in the Automator editor or asks to import into Shortcuts, cancel. In Finder, choose Go → Go to Folder, enter ~/Library/Services, and copy the workflow there. Create Services inside ~/Library if needed.

Test the browser’s Services menu first. If that works but the shortcut does not, check the service’s checkbox and shortcut conflicts. Keyboard shortcuts are optional.

Optional Excel formula tools

Install the other two workflows to copy a hyperlink formula from the browser and write it into Excel. Their shortcut entries are also under General.

Suggested keys: ⌃⌥C for HLT - Copy Excel Hyperlink and ⌃⌥V for HLT - Paste Excel Formula. The writer replaces the active cell; use an empty test workbook first. Wait for copying to finish before switching to Excel.
